## Incidental Steal

This mod updates the **Incidental Steal** passive skill so it works with all physical skills, including multi-target ones,
for **Octopath Traveler 0** using **UE4SS**.

## Requirements

- Octopath Traveler 0
- [UE4SS experimental latest](https://github.com/UE4SS-RE/RE-UE4SS/releases/tag/experimental-latest) — scroll down and download the release asset named like `UE4SS_vX.X.X-XXXX-gXXXXXXXX.zip`

## Installation

1. Locate your `UE4SS\Mods` folder `Octopath_Traveler0\Binaries\Win64\ue4ss\Mods`
2. Extract the content of the archives into the mods folder
3. Launch the game.

## Notes

- Make sure UE4SS is installed and working before using this mod.
- If the mod does not load, verify the folder name and file placement.

## Uninstallation

1. Close the game.
2. Remove the **Incidental Steal** folder from `UE4SS\Mods`.
