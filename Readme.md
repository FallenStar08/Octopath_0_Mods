# Octopath Traveler UE4SS Mods

A collection of mods for Octopath Traveler 0 using UE4SS.

## Overview

This repository contains a collection of small mods I made for Octopath Traveler 0

## Requirements

- Octopath Traveler 0
- UE4SS installed and set up
- Basic knowledge of mod installation and configuration

## Usage

Load the mods through UE4SS according to your setup. Refer to UE4SS documentation for detailed instructions on enabling and configuring mods.

## Notes

This repo isn't meant as the way to install these mods, visit my [Nexus Mods page](https://www.nexusmods.com/profile/Fararagi/mods?gameId=8425) for releases. (Even if they're just raw files anyway)
